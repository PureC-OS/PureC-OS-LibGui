# PureC-OS-LibGui

libgui (PureGUI 2) is the GUI toolkit of PureC OS: windows, widgets, layout
and themes on top of the `videod` display server (`video-backend`). Written
in C, linked statically (`libpg.a`). Programs built on it: `login`,
`terminal`, `settings`.

## Features

- **Application loop**: `pg_init` / `pg_run` / `pg_quit`, timers
  (`pg_timer_add`), file descriptor watches (`pg_fd_watch`, `poll`),
  `pg_hold` to keep running without windows.
- **Windows** drawn by the client (CSD): 34 px title bar with minimize,
  maximize and close, move by the title bar, resize by edges and corners with
  cursors, double click maximizes, minimum size; roles normal, background,
  panel, popup.
- **Double buffering**: a window is drawn into a private buffer; only the
  finished changed rows are copied into the buffer shared with `videod`
  before `DAMAGE`, so the server never shows a half-drawn frame.
- **Retained widget tree** with classes (`measure`, `height_for_width`,
  `arrange`, `draw`, `event`), signals `CLICKED`, `CHANGED`, `ACTIVATE`,
  `DESTROY`; damage is computed by the library. Keyboard focus with Tab.
- **Layout**: box, grid (spans), stack, scroll, card; margins, alignment,
  expansion, height for width.
- **Widgets**: label, icon, badge, key/value row, separator, spacer, progress,
  ring, image, drawing area, button (5 styles), toggle, checkbox, radio,
  slider, text entry (selection, password), segmented control, tabs,
  dropdown and context menu (popup windows), list and sidebar.
- **Canvas** (`pgc_*`): anti-aliased rounded rectangles, strokes, gradients,
  shadows, circles, rings, lines, images, clipping, Noto Sans and JetBrains
  Mono text, Material Design icons.
- **Themes**: 11 palettes; the theme comes from `PG_THEME`,
  `~/.config/purec/appear.ini` or `/config/appear.ini` and every window
  follows a change of that file at once.

## Using it

```c
#include "pg/pg.h"

static void clicked(struct pg_widget *w, void *data) { pg_quit(0); }

int main(int argc, char **argv)
{
    if (!pg_init(argc, argv))
        return 1;
    struct pg_window *win = pg_window_new("Hello", 320, 160, PG_WINDOW_RESIZABLE);
    struct pg_widget *box = pg_vbox(12);
    pg_box_set_padding(box, 20, 20, 20, 20);
    pg_widget_add(box, pg_label_new("Hello, PureC OS"));
    struct pg_widget *b = pg_button_new("Close", PG_NO_ICON, PG_BUTTON_PRIMARY);
    pg_widget_on(b, PG_SIGNAL_CLICKED, clicked, NULL);
    pg_widget_add(box, b);
    pg_window_set_child(win, box);
    int code = pg_run();
    pg_shutdown();
    return code;
}
```

Link order: `libpg.a libvb.a libpurec.a` (with `crt0.o` and
`linker-userspace.ld` of the PureC OS tree).

## Build

Inside the PureC OS tree (this repository is the `PureC-OS-LibGui` submodule):

    make -C PureC-OS-LibGui            # bin/libgui/libpg.a
    make -C PureC-OS-LibGui package    # bin/libgui/libgui-VERSION-1-x86_64.pkg.tar.gz (+ .sig)
    python3 mk/pkg/publish.py --registry Trusted bin/libgui/libgui-VERSION-1-x86_64.pkg.tar.gz

The package installs `/usr/lib/libpg.a` and `/usr/include/pg/*.h`; on PureC OS
`pkg -S libgui`. Fonts and icons are generated by `tools/gen_font.py` into
`include/pg/font_data.h` and `src/font_data.c`.

## Layout

| Path | Contents |
|---|---|
| `include/pg/` | Public API: `pg.h` includes everything |
| `src/app.c` | Event loop, timers, fd watches |
| `src/window.c` | Windows, decorations, input dispatch, double buffer |
| `src/widget.c` | Widget tree, signals, measure and place |
| `src/containers.c` | box, grid, stack, scroll, card |
| `src/widgets_*.c` | Widgets |
| `src/canvas.c` | Drawing primitives and text |
| `src/theme.c` | Themes and `appear.ini` |
